# 123apps 繁體中文全能媒體工具網站 (MediaTools WebApp) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 打造一款 100% 前端 WASM / Web API 驅動、零後端成本、媲美 123apps 繁體中文質感與功能的全能媒體工具平台。

**Architecture:** 基於 Vite + React + TypeScript 的單頁應用 (SPA)，使用現代 Vanilla CSS (Glassmorphism 玻璃擬態與 CSS Custom Properties) 提供高質感 UI。媒體運算採用 `@ffmpeg/ffmpeg` WASM、`pdf-lib`、`pdfjs-dist` 與 Web Audio API 於瀏覽器端純本地執行。

**Tech Stack:** React 18+, Vite, TypeScript, `@ffmpeg/ffmpeg`, `@ffmpeg/util`, `pdf-lib`, `pdfjs-dist`, `jszip`, Lucide Icons, Web Audio API, Canvas API.

## Global Constraints
- 所有畫面文字一律使用繁體中文 (Traditional Chinese, zh-TW)。
- 所有媒體運算必須 100% 於瀏覽器端 (Client-Side) 執行，不得呼叫第三方後端 API。
- 所有 UI 必須採用現代質感 (Dark Mode/Glassmorphism 玻璃擬態、平滑漸層、微妙 Hover 動畫)。
